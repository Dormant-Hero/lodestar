# Contributing to Lodestar

Thank you for wanting to help!

**Lodestar does not accept pull requests.** Please don't send code changes; they will be closed without review.
Instead, open an [issue](https://github.com/Dormant-Hero/lodestar/issues):

- **Found a bug?** Use the *Bug report* template: what you did, what happened, what you expected, your distro, and
  how you run Lodestar (AppImage or built from source). Screenshots help a lot.
- **Have an idea?** Use the *Suggestion* template: what you'd like and why it would help you.

Themes are very welcome too, as their own thing: make one with the theme creator and share the `.zip` wherever you
like (see [THEMES.md](THEMES.md)).
