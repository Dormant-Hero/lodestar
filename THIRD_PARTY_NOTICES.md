# Third-party notices

Lodestar is built from its own code plus the open-source work listed here. As far as we know
every part below allows redistribution (the one open point is noted at the ROM identification
database); the notices and licence texts they ask for are reproduced in this file. The same text is built into the app (menu → About Lodestar → Credits).

This file is generated by `tools/gen-third-party-notices.py` from `Cargo.lock` and the files
in `tools/third-party/`. Do not edit it by hand: change those files and run `python3 -I
tools/gen-third-party-notices.py` again (a test fails when a library is missing).
